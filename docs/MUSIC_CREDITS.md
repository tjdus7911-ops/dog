# 멍글런너 음원 출처·라이선스 기록

멍글런너의 음악은 **외부 녹음 음원을 사용하지 않습니다.**
퍼블릭 도메인 작곡(악보)을 멍글마을이 직접 편곡해 `shared/runner.ts`에 음표 데이터로 적고,
브라우저의 Web Audio API로 피아노 소리를 합성해 재생합니다(`client/src/runner/music.ts`).
장애물 패턴도 같은 음표 데이터에서 만들기 때문에 음악과 판정 박자가 항상 일치합니다.

## 편곡 내용 (엘리제를 위하여)
- 3/8박자 주제(A) → 반복 → 가운데 부분(원곡 9~12마디 흐름을 바탕으로 단순화) → 주제, 2절은 한 옥타브 위 오르골 소리를 겹쳐 밝게, 끝은 리타르단도.
- 원곡의 13~22마디 연결부와 B·C 섹션은 게임 길이(약 60초)와 난이도에 맞게 생략·단순화했습니다.
- 템포는 고정 BPM이 아니라 마디마다 다른 템포 배율(프레이즈 끝 늘이기, 마지막 리타르단도)을 적용하고, 이 템포 지도로 박자 타임라인을 계산합니다.

## 외부 녹음을 쓰게 될 경우 (2차 이후)
- Musopen 등에서 **퍼블릭 도메인(CC0/PD) 또는 상업적 사용·수정·재배포가 허용된 라이선스**로 명시된 녹음만 사용합니다.
- 사용 전 이 표에 녹음 출처 URL, 연주자, 라이선스, 확인 날짜를 기록합니다.
- 라이선스가 불명확한 녹음, 유튜브 음원, 상업 음반은 사용하지 않습니다.
- 녹음 음원을 쓰는 코스는 그 녹음에 맞춰 비트 타임라인을 따로 만들어야 합니다(현재 합성 방식과 다름).
