# 🐾 멍글마을 (Mungle Village)

> 우리 강아지와 함께 걷고, 만나고, 자랑하는 **로우폴리 3D 반려견 산책 커뮤니티**

사람 아바타를 직접 조작하고, 목줄을 찬 강아지가 보호자를 따라 함께 산책합니다.
같은 공원에 접속한 다른 보호자와 **실시간으로** 만나고, 채팅하고, 친구가 되어 함께 걸을 수 있습니다.

---

## 실행 방법

필요 환경: **Node.js 22.5 이상** (내장 `node:sqlite` 사용 — 별도 DB 설치 불필요)

```bash
npm install          # 루트에서 한 번 (client/server 워크스페이스 함께 설치)

# 개발 모드: 서버(3001) + 클라이언트(5173) 동시 실행
npm run dev
# → http://localhost:5173 접속

# 배포/시연 모드: 클라이언트 빌드 후 서버 하나로 실행
npm run build
npm start
# → http://localhost:3001 접속
```

**멀티플레이 확인:** 브라우저 창 2개(또는 일반 창 + 시크릿 창)에서 각각 다른 계정으로 가입하면
같은 공원에서 서로의 아바타·강아지가 실시간으로 움직이는 것을 볼 수 있습니다.
같은 와이파이의 휴대폰에서는 `http://<PC의 IP>:5173` 으로 접속하세요.

**자동 테스트:**

```bash
npm test             # 아래 두 가지를 모두 실행
npm run test:multi   # 다중 사용자 통합 테스트 (58개) — 실제 서버를 임시 DB로 띄우고 여러 클라이언트로 검증
npm run test:ai      # AI 사진 분석기 테스트 (13개) — 가짜 API 응답으로 요청 형식·결과 변환 검증
```

### 환경 변수 (선택)

| 변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3001` | 서버 포트 |
| `MUNGLE_PARK_CAPACITY` | `30` | 공원 1곳당 동시 접속 인원 제한 |
| `MUNGLE_ADMINS` | (없음) | 운영자 권한을 줄 **로그인 아이디** 목록(쉼표 구분). 해당 아이디로 **가입할 때** 운영자 권한이 부여됩니다 |
| `MUNGLE_DATA_DIR` | `server/data` | DB·업로드 사진 저장 위치 |
| `ANTHROPIC_API_KEY` | (없음) | **AI 강아지 사진 분석** 키 (Claude API). 없으면 분석 기능이 '사용 불가'로 표시되고 수동 선택만 가능 |
| `MUNGLE_AI_MODEL` | `claude-sonnet-5-5` | 사진 분석에 쓸 Claude 모델 |

예: `ANTHROPIC_API_KEY=sk-ant-... npm run dev` (Windows PowerShell: `$env:ANTHROPIC_API_KEY="sk-ant-..."; npm run dev`). 예시는 `server/.env.example` 참고.

## 실제로 구현한 기능

### 1~2단계: 3D 공원 · 사람 아바타 · 강아지 산책
- **로우폴리 중앙 공원**: 분수대, 광장, 순환·방사형 산책로, 잔디, 벚꽃/일반/침엽수 70그루, 꽃밭, 벤치, 가로등, 울타리, 건물 3채(강아지 집 입구 포함), 구름, 배경 언덕 — 모두 코드로 생성한 실제 3D 지오메트리 (시안 이미지를 배경으로 쓰지 않음)
- **SD 비율 로우폴리 사람 아바타**: 큰 머리·작은 몸, 파츠 조합(헤어 5종·상의 3종·하의 3종·모자 2종·액세서리 2종 + 색상), 공통 애니메이션 뼈대
- **로우폴리 강아지 아바타**: 파츠 조합(체형 3·털 길이 2·귀 3·꼬리 4·주둥이 3·무늬 5 + 털색/무늬색/하네스색), 견종 유형 프리셋 8종
- 사람과 강아지 모두 **flatShading 무광 재질**로 스타일 통일 (PBR·사실적 털·복잡한 텍스처·실시간 그림자맵 미사용, 발밑 원형 그림자만 사용)
- **강아지 산책 AI**: 보호자 오른쪽에서 함께 걷기/달리기, 멈추면 주변 냄새 맡으며 돌아다니기 → 주변 살피기 → 앉기, `앉아!` 명령, 꼬리 흔들기
- **목줄**: 사람 오른손 ↔ 강아지 하네스를 잇는 Verlet 로프 (중력으로 처지고 이동 시 따라옴)
- 강아지가 목줄 길이 이상 멀어지지 않고, 나무·분수대·건물 등 장애물에 끼이면 보호자 곁으로 복귀
- **발 미끄러짐 방지**: 다리 애니메이션 위상을 실제 이동 거리 ÷ 보폭으로 계산 (걷기/달리기 보폭 보간)
- **3인칭 카메라**: 수평 360° 회전, 상하 각도 제한, 확대/축소, 앞으로 걸을 때 천천히 뒤쪽으로 정렬

### 아바타 만들기 (v2 디자인)
- 시안 레이아웃: 왼쪽 **3D 미리보기 정원**(드래그 360° 회전·줌, 크게 보기, 사람/강아지 시점 전환, 걷는 모습 보기) + **아바타 예시 4종**(누르면 적용), 오른쪽 탭별 커스터마이징, 하단 다음 단계 버튼
- **항목별 실제 3D 썸네일**: 헤어·상의·하의·신발·모자·액세서리·견종·무늬·귀·주둥이·꼬리 썸네일은 그림 파일이 아니라 실제 3D 모델에 그 옵션을 적용해 렌더링한 이미지 (현재 피부색·머리색·털색이 그대로 반영)
- 모든 변경은 3D 미리보기에 실시간 반영, 저장하면 공원 속 내 캐릭터와 다른 사용자 화면에도 반영
- 사람: 피부색 5 · 헤어 7(단발·똥머리·양갈래·긴머리·숏컷·포니테일·삐죽) · 머리색 9 · 상의 5종(후드·티·줄무늬·멜빵·재킷) · 하의 3종 · 신발 2종(운동화·부츠) · 모자 4종(캡·버킷햇·비니·헤드폰) · 액세서리 4종(동그란/네모 안경·백팩·크로스백) + 의상 색상 15
- 강아지: 견종 유형 10 · 체형 3 · 털 길이 2 · 털색 9 · 무늬 5 + 무늬색 · 귀 3 · 주둥이 3 · 꼬리 4 · 목줄/하네스 색 6
- 실제 강아지 사진 등록(PNG/JPG/WEBP, 서버에서 파일 형식·크기 검증) → 프로필 팝업에 표시

### 캐릭터 모델 (v2)
- **사람**: 머리가 크고 몸이 작은 SD 비율, 둥근 얼굴·볼터치, 하이라이트가 있는 세로 눈, 웃는 입, 매끈한 곡면 앞머리와 옆머리(블록형 머리 폐지), 둥근 손·신발, 몸에 이어지는 후드·소매·멜빵끈
- **강아지**: 큰 머리·둥근 몸·짧은 다리, 견종별 귀(쫑긋·늘어짐·반접힘)와 주둥이 길이, 하이라이트 있는 눈과 코, 목걸이 + 금색 이름표 + 가슴 하네스 + 목줄 고리(목줄 연결점)
- 둘 다 둥근 저폴리 도형 + 플랫 셰이딩(면이 살아 있는 로우폴리)으로 스타일 통일
- **성능**: 수십 개 파츠를 관절별로 하나의 메시로 병합 → 캐릭터 1명당 약 7번만 그림. 같은 모습은 지오메트리를 공유(캐시)
- 이전 버전에 저장된 아바타는 새 항목 기본값으로 자동 보정 (기존 데이터 유지)

### AI 강아지 사진 분석
- 정면(필수)·측면·전신 사진 최대 3장 업로드 → 서버가 **Claude Vision API**로 분석
- 견종 유형·털색·털 길이·귀·꼬리·체형·무늬·주둥이를 **미리 만든 파츠 값 중에서만** 고르도록 강제(도구 호출 스키마) → 매번 새 모델을 만들지 않고 파츠 조합으로 아바타 생성
- 결과(추정 견종·요약·신뢰도)를 보여 주고 즉시 3D에 적용, 아래 항목에서 자유롭게 수정 가능, 정면 사진을 프로필 사진으로 쓰기
- 서버 검증: 이미지 형식·크기, 정면 필수, 결과 값 재검증, 강아지가 없는 사진 안내, 사용자당 시간당 10회 제한
- API 키가 없으면 '사용 불가'로 정직하게 표시하고 수동 선택만 제공

### 실시간 멀티플레이 (MVP 필수)
- 여러 사용자가 같은 공원에 동시 접속, 다른 사용자의 **사람 + 강아지 아바타** 실시간 표시
- 위치·방향·걷기/달리기/대기/인사 모션, 강아지 위치·모션(앉기·살피기·인사 포함) 동기화 (10Hz)
- 닉네임 · 강아지 이름 이름표
- 입장/퇴장 처리, 같은 계정 중복 접속 시 이전 연결 종료, 재접속 시 자동 재입장
- **지연 보정**: 140ms 버퍼 보간 + 짧은 외삽 후 정지 → 순간이동처럼 보이는 현상 최소화
- 공원 3곳 × 정원(기본 30명) 제한, 자동 배정, 공원 이동 메뉴에서 실제 인원 표시
- **서버 측 검증**: 비정상 속도(순간이동) 패킷 거부 후 위치 보정, 월드 경계 제한, 강아지 거리 제한, 잘못된 패킷 무시

### 실시간 채팅
- 같은 공원 공개 채팅 (서버 경유, 다른 공원에는 전달 안 됨) + 전송 시간 표시
- 가까운 사용자(16m 이내)에게만 머리 위 **말풍선** 표시
- 친구 간 **1:1 채팅** (DB 저장, 대화 기록, 안 읽은 메시지 수, 읽음 처리)
- 알림: 친구 신청·수락, 1:1 메시지 (토스트 + 🔔 알림함 + 배지)
- **욕설 필터** (글자 사이 공백·기호 우회 대응), **도배 방지** (빈도 제한 + 같은 문장 반복 → 일시 제한)

### 친구
- 아바타·강아지 클릭 → **프로필 팝업**: 사람 아바타 3D 미리보기, 닉네임, 강아지 이름·사진·소개
- 친구 신청 상태 5종: 신청 가능 / 신청 중(취소 가능) / 받은 신청(수락·거절) / 친구 / 차단됨
- 친구 목록: 온라인·오프라인, 친구가 있는 공원, 메시지 보내기, **함께 산책하기(친구 공원으로 이동)**, 친구 삭제, 차단
- **개인정보 설정**: 접속 상태 공개 / 공원 위치 공개 / 친구 신청 받기 — 서버에서 적용 (친구라도 비공개면 조회 불가)

### 함께 산책
- 친구 공원으로 이동해 같은 공원에서 각자 아바타를 조작, 각자의 강아지가 자동으로 따라감, 걷는 중 채팅
- **강아지 인사**: 강아지끼리 1.5m 이내로 가까워지면 서로 바라보며 깡충깡충 + 빠른 꼬리 흔들기 (모든 사용자에게 동기화)
- 👋 인사하기 동작 (다른 사용자에게 동기화)

### 신고 · 차단 · 운영
- 차단: 친구 관계·신청 정리, 서로의 채팅 차단, 같은 공원에서 서로의 아바타 숨김, 차단 목록·해제
- 신고: 사유 선택 + 상세 내용, 서버가 대상의 최근 공원 채팅을 **서버 기록 기준**으로 자동 첨부, 시간당 10회 제한
- 운영자 화면: 신고 목록, 처리 완료/기각, 24시간·7일 이용 정지(즉시 접속 종료)·해제

### 보안 · 개인정보
- 아이디/비밀번호 로그인 (scrypt 해시, 세션 토큰은 해시만 DB 저장, 14일 만료), 로그인 시도 제한
- 모든 실시간 이벤트에 소켓 인증, 친구 여부·차단·개인정보 설정을 **서버에서 재검증**
- 다른 사용자에게는 닉네임·아바타·강아지 정보만 공개 (로그인 아이디 비공개)
- 업로드 사진은 무작위 파일명 + 매직 바이트 검증

### 성능 최적화
- 나무·꽃·풀·울타리·언덕을 **InstancedMesh**로 묶어 드로우콜 최소화
- 재질·지오메트리 캐시 공유, 실시간 그림자맵 대신 원형 그림자
- 성능 저하 시 해상도(DPR) 자동 하향, 멀리 있는 사용자 이름표 숨김
- 정지 상태에서는 위치 패킷 전송 최소화 (변화 시에만 + 1초 간격 유지 신호)

## 사용한 에셋

**외부 3D 모델·텍스처·이미지 에셋은 사용하지 않았습니다.**
사람·강아지·공원의 모든 3D 오브젝트는 Three.js 기본 도형(상자, 이십면체, 원기둥, 원뿔 등)을 조합해 코드로 만든 로우폴리 모델입니다.

- 글꼴: Google Fonts **Jua**, **Gowun Dodum** (OFL 라이선스, 웹 로드 실패 시 시스템 글꼴 사용)
- 아이콘: 시스템 이모지
- 라이브러리: React, Three.js, React Three Fiber, Drei, Tailwind CSS, Zustand, Socket.IO, Express

모델은 `HumanDriver` / `DogDriver` 인터페이스로 애니메이션 상태를 받고, 빌더가 같은 이름의 관절(head, armL, legFL …)을 돌려주는 구조입니다.
추후 GLB 모델로 교체할 때는 `client/src/game/models/humanModel.ts`·`dogModel.ts` 가 같은 관절 이름을 가진 GLB를 불러오도록 바꾸면 애니메이션·목줄·썸네일이 그대로 동작합니다.

## 프로젝트 구조

```
shared/                 # 클라이언트·서버 공용
  avatar.ts             #   아바타 파츠 정의 + 서버 검증 함수
  protocol.ts           #   실시간 프로토콜 타입·상수
  world.ts              #   공원 레이아웃(결정적 생성) + 충돌 처리
server/
  src/index.ts          #   REST API (인증·프로필·사진·운영)
  src/realtime.ts       #   Socket.IO: 공원·동기화·채팅·친구·DM·차단·신고
  src/db.ts             #   SQLite 저장소 (Supabase 이전 시 이 파일만 교체)
  src/auth.ts           #   비밀번호 해시·세션 토큰
  src/moderation.ts     #   욕설 필터·도배 방지·요청 제한
  src/dogAnalyzer.ts    #   AI 강아지 사진 분석 (Claude Vision API)
  test/multiplayer.test.ts  # 다중 사용자 통합 테스트
client/src/
  game/                 #   3D: World, Players, CameraRig, Leash, dogBrain, thumbs(옵션 썸네일 렌더러)
  game/models/          #   humanModel·dogModel(파츠 빌더), bake(관절별 병합·캐시), Human·Dog(애니메이션)
  net/                  #   socket.ts (서버 연결), remote.ts (스냅샷 보간)
  ui/                   #   HUD, 아바타 편집, 친구·DM·알림·설정·운영 패널
```

1. **AI 분석 실사용 점검** — API 키 설정 후 다양한 견종 사진으로 정확도 확인, 필요 시 프롬프트·파츠 보강
2. **개인 강아지 집 (5단계)** — 로우폴리 실내 공간, 사진 액자 확대, 가구·테마, 방명록·좋아요, 친구 집 방문 (프로필 팝업의 "준비 중" 버튼 활성화)

6. **모바일 최적화 · QA (7단계)** — 실기기 성능 측정, 저사양 모드, 접근성 점검, 욕설 사전 운영 도구
