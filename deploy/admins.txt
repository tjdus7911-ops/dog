# 멍글마을 운영자 목록
#
# 운영자로 지정할 '이미 가입한' 아이디를 한 줄에 하나씩 적어 주세요. (# 뒤는 메모)
# GitHub 에서 이 파일을 고쳐 저장하면, 서버가 5~10분 안에 새 내용을 받아 운영자로 바꿔요.
#
#   예)  mungle_owner          ← 이 계정을 운영자로
#        -old_helper           ← 앞에 '-'를 붙이면 운영자 권한을 회수
#
# 꼭 지켜 주세요
#  1. 먼저 그 아이디로 가입(또는 로그인)이 되는지 확인한 뒤에 적어 주세요.
#     목록에 적힌 '뒤에' 가입한 계정은 안전을 위해 운영자가 되지 않아요.
#     (다른 사람이 같은 아이디로 먼저 가입해 운영자가 되는 일을 막기 위함)
#  2. 비밀번호·토큰 같은 정보는 절대 적지 마세요. 아이디만 적어요.
#  3. 줄을 지우기만 하면 권한은 그대로예요. 회수하려면 '-아이디'로 적어 주세요.
