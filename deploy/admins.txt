# 멍글마을 운영자 목록
#
# 운영자 지정 절차 (계정 주인 확인 + 저장소 주인 확인 — 둘 다 맞아야 지정돼요)
#  1. 운영자가 될 계정으로 멍글마을에 로그인
#  2. 개인정보·차단 설정 창 맨 아래 '운영자 계정 등록' → '확인 코드 만들기'
#     (그 계정에만 보이는 1회용 코드, 24시간 유효 — 예: AB12-CD34-EF56)
#  3. 이 파일 맨 아래에 '아이디 코드' 한 줄을 적고 저장(Commit)
#       예)  mungle_owner AB12-CD34-EF56 최고     ← 끝의 '최고'는 최고 관리자 표시 (없으면 일반 운영자)
#  4. 5~10분 뒤 새로고침하면 메뉴에 '관리자 페이지'가 생겨요. (줄은 그대로 둬도 되고, 코드는 이미 사용돼 다시 쓸 수 없어요)
#
#  · 아이디만 적힌 줄은 무시돼요. (아이디가 같다는 이유만으로는 운영자가 되지 않아요)
#  · 권한 회수: '-아이디' 줄을 추가 (예: -old_helper). 줄을 지우기만 해서는 회수되지 않아요.
#  · 비밀번호·로그인 토큰은 절대 적지 마세요. 확인 코드는 한 번 쓰면 끝나고 그 계정에만 맞아요.
